# 🎮 Simon Says Game

A full-stack Simon Says game built with a frontend and backend.

## Features

* 🎮 Interactive Simon Says gameplay
* 🧠 Memory-based game
* 📊 Score tracking
* 📱 Responsive UI
* 🔗 Frontend + Backend integration

## Tech Stack

* **Frontend:** HTML, CSS, JavaScript
* **Backend:** Node.js, Express.js
* **Database:** MongoDB

## Run Locally

Clone the repository:

```bash
git clone https://github.com/Kanhaiya1729/Simon-Says-Game.git
cd Simon-Says-Game
```

Install dependencies:

```bash
cd frontend
npm install

cd ../backend
npm install
```

Create a `.env` file in the backend folder and add your environment variables.

Start the backend:

```bash
npm start
```

Start the frontend:

```bash
npm start
```
